# Step 3: 智能构建目标文档工作流

## 概述

Step 3 负责综合论文分析和用户需求，使用子Agent构建详细的PPT目标文档。

## 角色

**主要角色**：Content Strategist (内容策略师)

## 输入

- `workspace/papers/analysis.json` - 论文分析结果
- `workspace/requirements.md` - 用户需求

## 输出

- `workspace/goal.md` - PPT目标文档

## 工作流程

### 3.1 spawn子Agent构建goal.md
```
Agent: 目标文档构建
description: "综合论文分析和用户需求，构建PPT目标文档"
prompt: |
  你是一个学术PPT规划专家。请根据以下信息，构建详细的PPT目标文档。

  【论文分析结果】
  {analysis_json}

  【用户需求】
  {requirements_md}

  请构建PPT目标文档，包含：
  1. PPT概述（标题、作者、单位、用途、时长、听众）
  2. 内容结构（章节划分、每章重点、时间分配）
  3. 核心要点（创新点、关键数据、重要图表）
  4. 视觉设计（配色方案、页面布局、图表风格）
  5. 讲解策略（开场白、重点强调、过渡语）
  6. 信息补全（缺失信息、补充建议、需要资源）

  请将结果写入：workspace/goal.md
```

### 3.2 保存目标文档
- 保存到 `workspace/goal.md`

## 输出示例

```markdown
# PPT目标文档

## 1. PPT概述
- 标题：微脉冲激光雷达系统设计
- 作者：张寒逸
- 单位：中国科学技术大学 物理学院
- 用途：学术会议汇报
- 时长：10分钟
- 听众：课程老师、同学

## 2. 内容结构
1. 封面（30秒）
2. 研究背景（1分钟）
3. 研究目的与创新点（1分钟）
4. 工作原理（2分钟）
5. 系统构成（2分钟）
6. 误差分析（1.5分钟）
7. 仿真结果（1.5分钟）
8. 结论（1分钟）
9. 致谢（30秒）

## 3. 核心要点
- 创新点1：双波长协同设计
- 创新点2：多误差源量化分析
- 创新点3：眼安全设计
- 关键数据：白天探测3.5~4.2km

## 4. 视觉设计
- 配色：深海蓝#003366 + 青碧绿#6699CC
- 布局：上标题栏+左文右图
- 图表：扁平化矢量风格

## 5. 讲解策略
- 开场白：介绍研究背景和动机
- 重点强调：创新点和关键数据
- 过渡语：自然衔接各章节

## 6. 信息补全
- 缺失：系统架构图
- 补充：搜索相关研究的示意图
- 资源：激光雷达系统图
```
