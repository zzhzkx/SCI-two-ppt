# Step 3: 智能构建目标文档工作流

## 概述

Step 3 负责综合论文分析和用户需求，使用子Agent构建详细的PPT目标文档。

## 角色

**主要角色**：Content Strategist (内容策略师)

## 输入

- `workspace/papers/analysis.json` - 论文分析结果
- `workspace/requirements.md` - 用户需求

## 输出

- `workspace/goal.md` - PPT目标文档

## 文档职责说明

`goal.md` 聚焦于**内容和策略**（做什么、给谁看、多长时间），视觉设计只写高层方向，详细规范交给后续步骤：
- **Step 4 审查后**：生成 `workspace/design_spec.md`（设计决策文档，给人读）
- **Step 5 Visual Designer**：从 design_spec 生成 `workspace/papers/spec_lock.md`（执行锁，给机器读）

## 工作流程

### 3.1 spawn子Agent构建goal.md
```
Agent: 目标文档构建
description: "综合论文分析和用户需求，构建PPT目标文档"
prompt: |
  你是一个学术PPT规划专家。请根据以下信息，构建详细的PPT目标文档。

  【论文分析结果】
  {analysis_json}

  【用户需求】
  {requirements_md}

  请构建PPT目标文档，包含：
  1. PPT概述（标题、作者、单位、用途、时长、听众）
  2. 内容结构（章节划分、每章重点、时间分配）
  3. 核心要点（创新点、关键数据、重要图表）
  4. 视觉设计（配色方案、页面布局、图表风格）
  5. 讲解策略（开场白、重点强调、过渡语）
  6. 信息补全（缺失信息、补充建议、需要资源）

  请将结果写入：workspace/goal.md
```

### 3.2 保存目标文档
- 保存到 `workspace/goal.md`

## 输出示例

```markdown
# PPT目标文档

## 1. PPT概述
- 标题：[论文标题]
- 作者：[作者姓名]
- 单位：中国科学技术大学 物理学院
- 用途：学术会议汇报
- 时长：10分钟
- 听众：课程老师、同学

## 2. 内容结构
1. 封面（30秒）
2. 研究背景（1分钟）
3. 研究目的与创新点（1分钟）
4. 工作原理（2分钟）
5. 系统构成（2分钟）
6. 误差分析（1.5分钟）
7. 仿真结果（1.5分钟）
8. 结论（1分钟）
9. 致谢（30秒）

## 3. 核心要点
- 创新点1：[创新点1]
- 创新点2：[创新点2]
- 创新点3：[创新点3]
- 关键数据：[关键数据]

## 4. 视觉方向（高层建议，详细规范由 design_spec.md 定义）
- 风格倾向：丰富图解 / 简约学术 / 数据驱动
- 配色倾向：蓝色调（光学/物理）/ 绿色调（生物）/ 紫色调（计算机）
- 特殊需求：公式清晰标注 / 图表为主 / 大量对比

## 5. 讲解策略
- 开场白：介绍研究背景和动机
- 重点强调：创新点和关键数据
- 过渡语：自然衔接各章节

## 6. 信息补全
- 缺失：[缺失1]
- 补充：搜索相关研究的示意图
- 资源：[资源1]
```
