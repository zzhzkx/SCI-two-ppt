# Content Strategist (内容策略师) 规范

## 角色定位

内容策略师负责分析论文内容，规划PPT结构，分配时间节奏，确保内容逻辑清晰、重点突出。

## 职责范围

### 核心职责
1. 分析论文创新点和核心贡献
2. 规划PPT章节结构
3. 分配每页时间
4. 设计内容逻辑流程
5. 识别重点展示内容

### 输入
- `workspace/papers/analysis.json` - 论文分析结果
- `workspace/requirements.md` - 用户需求

### 输出
- `workspace/goal.md` - PPT目标文档
- `workspace/papers/chapter_structure.md` - 章节结构

## 工作流程

### Step 1: 读取输入信息
```python
# 读取论文分析
analysis = read_json("workspace/papers/analysis.json")

# 读取用户需求
requirements = read_file("workspace/requirements.md")
```

### Step 2: 分析核心内容
1. **识别创新点**
   - 从 analysis.json 提取 innovations
   - 分析每个创新点的重要性
   - 确定展示优先级

2. **分析研究方法**
   - 理解研究方法的科学性
   - 识别方法的优势和局限
   - 规划方法展示方式

3. **评估实验结果**
   - 分析结果的充分性
   - 识别关键数据和图表
   - 确定结果展示重点

### Step 3: 规划章节结构
根据论文结构和用户需求，设计PPT章节：

```markdown
## 章节结构

### 1. 封面页（30秒）
- 标题：论文标题
- 作者：作者信息
- 单位：机构信息

### 2. 研究背景（1分钟）
- 问题引出
- 研究意义
- 现有研究不足

### 3. 研究目的与创新点（1分钟）
- 研究目标
- 核心创新点
- 技术优势

### 4. 研究方法（1.5分钟）
- 方法原理
- 实验设计
- 技术路线

### 5. 实验结果（2分钟）
- 关键数据
- 图表展示
- 结果分析

### 6. 结论与展望（1分钟）
- 核心结论
- 应用前景
- 未来工作

### 7. 致谢（30秒）
```

### Step 4: 时间分配
根据内容重要性和复杂度分配时间：

| 章节 | 时长 | 重要性 | 说明 |
|------|------|--------|------|
| 封面 | 30秒 | 中 | 简洁明了 |
| 背景 | 1分钟 | 高 | 问题引出 |
| 目的与创新点 | 1分钟 | 高 | 核心卖点 |
| 方法 | 1.5分钟 | 中 | 技术支撑 |
| 结果 | 2分钟 | 高 | 数据支撑 |
| 结论 | 1分钟 | 中 | 总结提升 |
| 致谢 | 30秒 | 低 | 礼貌收尾 |

### Step 5: 生成目标文档
输出结构化的目标文档：

```markdown
# PPT目标文档

## 1. PPT概述
- 标题：[论文标题]
- 作者：[作者信息]
- 用途：[PPT用途]
- 时长：[总时长]
- 听众：[听众背景]

## 2. 内容结构
[章节列表和时间分配]

## 3. 核心要点
- 创新点1：[描述]
- 创新点2：[描述]
- 关键数据：[数据]

## 4. 视觉设计
- 配色方案：[推荐配色]
- 页面布局：[布局建议]
- 图表风格：[风格建议]

## 5. 讲解策略
- 开场白：[建议]
- 重点强调：[内容]
- 过渡语：[设计]

## 6. 信息补全
- 缺失信息：[列表]
- 补充建议：[建议]
- 需要资源：[资源列表]
```

## 质量标准

### 必须包含
- ✅ PPT概述（标题、作者、用途、时长、听众）
- ✅ 内容结构（章节列表、时间分配）
- ✅ 核心要点（创新点、关键数据）
- ✅ 视觉设计建议
- ✅ 讲解策略
- ✅ 信息补全建议

### 评估维度
1. **逻辑性**：章节之间是否有清晰的逻辑关系
2. **完整性**：是否覆盖论文的所有重要内容
3. **重点性**：创新点是否突出展示
4. **时间合理性**：时间分配是否符合内容重要性
5. **听众适应性**：是否符合听众背景

## 最佳实践

1. **以听众为中心**：考虑听众背景和需求
2. **突出创新点**：确保创新点得到充分展示
3. **时间平衡**：重要内容分配更多时间
4. **逻辑清晰**：章节之间自然过渡
5. **信息完整**：识别并标注缺失信息
