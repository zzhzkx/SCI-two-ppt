# UI风格设计

## 配色方案

设计灵感：激光雷达领域特有的激光蓝绿光谱、大气散射光学特征。

- **主色**：#003366（深海蓝）- 标题、边框、图表主轴
- **辅色**：#6699CC（青碧绿）- 副标题、章节分隔条
- **强调色**：#FF6600（琥珀橙）- 关键数据高亮、重点标注
- **背景色**：#FFFFFF（白色）- 幻灯片底色

## 字体规范

- **标题**：Arial Bold 36pt，主色#003366
- **副标题**：Arial Semibold 24pt，辅色#6699CC
- **正文**：Arial 18pt，文字主色#333333
- **公式**：Cambria Math 20pt，居中排列
- **图表标注**：Arial 14pt，文字辅色#666666

## 页面布局

### 封面页
- 标题居中偏上
- 副标题及作者信息居中偏下
- 背景使用主色到辅色的渐变

### 正文页
- 上方1/6区域：页面标题栏
- 左侧55%：内容区域
- 右侧45%：图表/示意图区域
- 底部8%：脚注区

### 章节过渡页
- 全屏主色背景
- 章节编号大字号显示
- 章节标题居中

## 图表风格

### 通用规范
- 所有图表使用主色#003366作为主要数据系列颜色
- 第二数据系列使用辅色#6699CC
- 需要突出对比时使用强调色#FF6600
- 图表背景透明或使用#F5F7FA浅灰白

## 动画建议

- 页面切换：淡入淡出（0.5秒）
- 内容出现：逐行显示（0.3秒间隔）
- 图表展示：先出现框架，再填充数据
- 禁止花哨动画，保持学术专业感
